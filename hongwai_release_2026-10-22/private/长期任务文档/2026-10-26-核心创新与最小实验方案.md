# 核心创新与最小实验方案

日期：2026-10-26。状态：**方案已记录，新增实验待实施；本轮未启动训练**。

本文件保存讨论形成的研究方向与执行顺序。候选创新点仍需实验支撑，不代表已证明新颖性或保证发表。最新进展以[项目长期状态](项目长期状态-CURRENT.md)为入口。

## 1. 工作目标

以合理工作量完成适合毕业投稿的增量改进论文，面向四区期刊，不要求全面超过现有方法或达到 SOTA。

保留必要的公平对照与真实报告。分区不对应固定 mIoU 门槛，不因某个指标不好而临时更换主指标，不将固定融合被弱来源拉低后的恢复幅度直接当作新结构贡献。

## 2. 候选论文主线

**图像引导的多源预测受约束残差校正。**

拟解决的问题：多个模型的预测存在置信度不一致、漏检与误检。固定平均和统一阈值无法分别处理不同位置的错误，因而结合原始图像线索及多源预测信息，学习逐位置的有界修正。

暂定题目：《融合局部信息与方向上下文的红外小目标多源预测校正方法》。最终题目随被实验支持的设计收敛；方向分支若无贡献，不保留对应题目表述。

| 候选贡献 | 需要证明什么 | 当前状态 |
|---|---|---|
| 图像与多源预测联合引导的空间校正 | 比固定融合及简单校正有效，图像信息确实有帮助 | 整体修正有效；图像信息独立贡献未验证 |
| 局部保持与方向上下文设计 | 关键分支在相同设置下有可重复的增益 | E1/E2/E4 已有部分对照，完整版本收益小且不一致 |
| 修正幅度约束 | 能改善准确性或减少误伤，避免过度改写 | 已实现有界残差；有无约束对照未完成 |

不硬凑多个创新点。残差、后处理、局部与方向信息本身不是首次提出；后续相关工作梳理需明确具体方法差异。可参考已有预测后处理工作 FEST：<https://www.sciencedirect.com/science/article/pii/S0950705125015588>。

## 3. 已有证据对方案的约束

最新 NUDT/SIRST3 诊断显示：

- 完整 LPSM 比验证集选择的融合阈值＋面积过滤，mIoU 分别高 7.288、2.421 个百分点。
- 完整版本相对 Anchor 分别为 -0.009、+0.160 个百分点；目前不能把巨大恢复幅度归功于方向分支。
- 验证集选择的较好单来源也能达到相近或更高 mIoU，必须纳入主表。
- 降低误报的收益会受到阈值选择影响，不能只比较所有方法的默认 0.5。
- SIRST3 与三个基础数据集重叠；不能用 NUDT＋SIRST3 宣称两份独立泛化验证。

完整结果及边界见 CURRENT 与独立工作区 `experiments/outputs/results/20261026_fusion_diagnostics/`。

## 4. 第一步：建立可复用实验清单

先检查配置、代码、日志与权重，不直接补跑。每个候选结果至少记录：

- 数据集、训练/验证/测试 ID、划分文件哈希；
- 四个预测来源的定义、权重哈希、预处理、软概率/硬掩码处理；
- 模型版本、输入通道、启用分支、修正幅度与损失；
- 种子、epoch、batch、精度与优化设置；
- 权重选择依据、指标实现、阈值/面积选择依据；
- 日志、权重、预测与结果的实际路径。

产出一份 CSV/JSON：逐项标记“可直接复用”“只需重新评估”“需要新训练”及原因。不同输入、教师、划分或测试选择方式的结果分开，不拼接为同一组受控实验。

## 5. 第二步：补齐完整方法对照

使用 NUAA-SIRST、NUDT-SIRST、IRSTD-1K 三套独立数据集；SIRST3 只作补充。先复用 NUDT 已完成结果，判断前两个数据集的已有权重是否能按同协议复评。

| 方法 | 比较目的 | 计算方式 |
|---|---|---|
| 原始 SCT | 外部强参考，说明实际性能位置 | 固定权重推理 |
| 四来源中验证集选较好单来源＋阈值 | 判断融合与修正是否值得 | 固定来源预测，不训练 |
| 两个 SCT 系来源平均 | 判断弱来源混入的影响 | 固定预测平均，不训练；已有结果可复用 |
| 固定四来源融合 | 修正网络的直接输入基线 | 固定预测平均，不训练 |
| 融合＋调阈值＋小区域过滤 | 排除仅由简单后处理带来的提升 | 只在验证集选择参数 |
| E1/Anchor | 分离普通修正网络与新增结构贡献 | 复用或训练 |
| E2/局部 LPSM | 检查局部设计作用 | 优先复用已有实验 |
| E4/完整 LPSM | 待评价的完整方法 | 复用或训练 |

固定模型及可复用预测上的阈值、过滤和统计不需要另训网络。主表同时报告较弱直接基线和较强参考，NUDT 不占优的结果也保留。

## 6. 第三步：最小核心设计消融

先核对现有输入与模块，精确定义消融，避免不同实验同时改变多个因素。

| 消融 | 控制要求 | 要回答的问题 |
|---|---|---|
| 仅预测信息／图像＋预测信息 | 保留同样的预测来源；图像派生特征也计入图像信息，不能留下泄漏；尽量保持修正骨干和参数规模一致 | 校正是否真正利用图像，而非仅学习概率重映射？ |
| 无幅度约束／有界残差 | 保留相同输入、骨干和训练设置；区分输出幅度限制与残差正则，先只改变一项 | 约束能否改善精度或减少误伤？ |
| Anchor／局部分支／完整版本 | 同一数据、来源、预算、种子和权重选择规则 | 新增分支是否带来收益？ |

消融配置中记录图像通道的处理方式及参数量变化；“去掉原始图像但保留所有图像派生特征”不能称为仅预测输入。

本轮优先前两项与已有 E1/E2/E4 的复用。暂不新增方向单独分支或其他复杂模块。若后续要宣称两分支协同，才补方向单独分支及必要容量对照。

## 7. 训练与执行顺序

1. 先完成清单与精确配置，确认统一输入与划分；本文件不是启动命令。
2. 首轮一个种子、统一短预算筛查；既有 4 epoch 设置兼容时复用。短训练用于判断方向，不作为最终收敛结论。
3. 只对保留的最终方法和关键对照，采用相同且足够的训练预算确认；根据验证曲线判断是否继续，不预设“30 epoch 必然足够”。
4. 关键差异较小时，优先为关键模型补重复种子，不要求每个变体全部重复。
5. 三张 A6000 按启动时的空闲情况并行分配独立作业；用户此前允许使用空闲卡，不代表可以中断其他人的进程。

完成清单后给出实际新增运行数与耗时估计。环境、数据、缓存和结果继续保存在服务器 `/DATA`，训练通过 tmux 等方式脱离会话运行并保留日志与退出码。

## 8. 固定评估与结果记录

- 主指标 mIoU；辅助报告 nIoU、F1、Pd、Fa，保持实现一致。Fa 同时保留历史口径与按区域编号复核口径并明确标记。
- 默认阈值结果与验证集选参数结果分列，测试集不参与阈值、面积、来源、checkpoint 或种子的选择。
- “验证集匹配 Pd”不保证测试集 Pd 相同，必须列出实际测试 Pd 与 Fa。
- 训练、验证和最终测试分开；对已有上游教师的历史测试选择明确披露，不能声称已消除历史泄漏风险。
- 方法间比较以相同输入和预算为前提；单 SCT 输入实验与四来源融合实验分别列出。
- 记录找回目标、额外漏检、移除误报和新增误报；正反案例都保留。
- 报告修正网络的额外参数、时间，并明确完整系统还包含上游多个模型的推理成本；未经测量不称“轻量”。
- 最终测试前冻结配置与模型选择规则。已有诊断已查看过测试集，后续结果需如实交代探索历史，不能伪称全新盲测。

## 9. 根据证据决定论文内容

| 观察结果 | 后续选择 |
|---|---|
| 图像信息或约束有可重复收益 | 重点组织为方法贡献，并给出相应消融和误伤解释 |
| LPSM 分支也有稳定收益 | 保留为结构设计，按真实幅度描述 |
| 分支长期与 Anchor 接近 | 简化结构；重新判断整体方法与常规修正器的区别，不把通用网络改名算作创新 |
| 整体仍仅修复弱融合且无额外设计收益 | 与用户/师兄讨论调整融合输入或校正机制，先定具体改动，不盲目堆模块 |

不要求每个指标、每个数据集全面获胜；也不靠挑种子、挑测试阈值或省略强对照建立论文结论。
