# SCTransNet 改进项目：现状结论与后续验证方案

> **整理日期：**2026 年 10 月 25 日  
> **代码版本：**GitHub `zzz-runnner/myPaper`，`main` 分支，2026-10-24 上传的 `hongwai_release_2026-10-22` 研究归档  
> **文档用途：**梳理当前研究工作、解释 Anchor 与 LPSM 的关系，明确后续验证方案，为红外小目标检测 SCI 论文准备实验依据。  
> **结论性质：**根据仓库代码、历史训练记录、实验报告与本次讨论整理；**未在本次整理中重新训练或独立运行完整推理**。

## 一、总体结论（先看这一节）

1. **研究任务明确：**以 SCTransNet 作为主要 baseline，研究**单帧红外小目标检测（像素级分割）**，目标是在保证误报率和检测率的同时，提高目标区域预测精度。
2. **现有成绩有提升，但属于历史探索结果：**与本地运行的 SCTransNet 官方 SIRST3 权重相比，IRSTD-1K 的 mIoU 从 68.03% 提升至 **73.2142%**，NUAA-SIRST 从 77.64% 提升至 **82.7020%**，分别提高约 **5.18、5.06 个百分点**。
3. **两套成绩不是同一个完整网络的结果：**IRSTD-1K 的主修正网络为 **Anchor Residual UNet**；NUAA-SIRST 的主修正网络为 **两个 LPSM Anchor Residual UNet 的预测融合**。两者的教师来源、输入通道和训练配置不同，但最终都叠加了 DFAwareNet、HFMNet 的概率融合及连通域后处理。
4. **LPSM 可以理解为 Anchor 思路的扩展版本：**沿用“教师预测 + 有界残差纠错”的方法框架，在类似的 U-Net 结构里增加局部保真与方向上下文模块；不是一个完全无关的全新任务网络。
5. **目前不能证明 LPSM 的方向模块有效：**保留的 NUAA 最优 LPSM 权重中，方向门控系数 `alpha` 为负，被 `clamp(0, 1)` 截为零，方向分支对输出不产生贡献。因此不能把已有提升归因于方向上下文，更不能宣称这里使用了真正的 Mamba selective scan。
6. **最主要的论文风险是实验方法，而不仅是模型性能：**历史测试集参与了 checkpoint、阈值和融合权重选择；两数据集没有完成同一个方法的公平对照与控制变量消融，现有 +5 点不能直接视为严格独立测试得到的“新算法净增益”。
7. **下一步建议：**先统一教师输入和实验协议，修复 LPSM 门控，在两个数据集上分别对 Anchor、局部模块、方向模块及完整 LPSM 做**相同条件**的短训练和对照。确认模块有效后，再讨论是否值得进行两网络输出融合。

## 二、这个项目具体在做什么？（通俗理解）

SCTransNet 原始任务是：输入红外图像，直接输出每个像素属于目标的概率。当前改进工作的重点转为：**先利用已有检测器给出预测，再由一个小网络学习纠正预测错误**。

可将其理解为“老师批改答卷”：

```text
红外原始图像
    │
    ├── 已有检测模型（Teacher）──→ 初始目标概率图
    │
    └── 图像特征提取（对比度、局部亮度、边缘、背景等）
                     │
                     ▼
            Anchor / LPSM 纠错网络
                     │
             输出有限幅度的修正量
                     │
                     ▼
         教师预测 + 修正量 → 新概率图
                     │
        加入 DFAwareNet、HFMNet 的预测
                     │
                     ▼
            阈值判断 + 小区域过滤
                     │
                     ▼
                最终目标掩码
```

核心思想可写为：

```text
Delta = residual_scale × tanh(Refiner(features))
P_refined = sigmoid(logit(P_teacher) + Delta)
```

- `P_teacher`：已有模型认为各像素属于目标的概率。
- `Refiner`：需要训练的纠错网络。
- `Delta`：纠错量；`tanh` 使其有界，减少对教师结果的过度修改。
- `P_refined`：修正后的目标概率图。

这里的 **Anchor（锚定）**，指将教师预测当作基础答案，只学习有限幅度的修正；**不是一种独立于教师模型的端到端单图预测网络**。

## 三、Anchor 与 LPSM 的关系

| 方面 | Anchor Residual UNet | LPSM Anchor Residual UNet |
|---|---|---|
| 核心思想 | 基于教师预测的有界残差纠错 | 同样基于教师预测的有界残差纠错 |
| 基础架构 | U-Net 风格编码器与解码器 | 类似的 U-Net 风格结构 |
| 额外模块 | 常规卷积块 | 局部保真卷积 + 方向累计上下文 + 门控 |
| 方向信息 | 无专门 LPSM 方向模块 | 设计上有，但最终保留权重里相关门控为零 |
| 当前最终应用 | IRSTD-1K | NUAA-SIRST |

**准确结论：**从网络构想上可以说“LPSM 是对 Anchor 的结构扩展”；但是**还不能说‘LPSM 经实验证明比 Anchor 更好’**，因为已有实验同时更换了教师、输入特征、训练数据规模及超参数，没有控制其他变量。

### LPSM 目前最关键的代码问题

源码 `train_lpsm_anchor_refiner_from_cache.py` 中：

```python
self.alpha = nn.Parameter(torch.tensor(0.0))
# ...
return x + self.alpha.clamp(0.0, 1.0) * gate * state
```

保留的两组 NUAA 权重中，`alpha` 约为 `-0.00014` 至 `-0.00020`；经 `clamp(0, 1)` 后取值为 `0`，从而：

```text
输出 = x + 0 × gate × state = x
```

这意味着方向分支虽被写进模型，但目前没有实际改变输出；在负数区间，`clamp` 也会阻断这一路通常的反向梯度。**修复建议**是尝试可学习的 Sigmoid 门控（或其他不会进入死区的参数化方式），再记录分支梯度和输出差异，**重新训练后再做消融**。修改代码并不会自动修好历史权重的科研结论。

另外，现有 LPSM 的四方向信息是通过 `torch.cumsum` 等运算实现的，**不等同于 MambaIR 的原始状态空间扫描模块**；真正启用官方 Mamba 算子的主要是作为外部预测来源的 DFAwareNet、HFMNet 等模型。

## 四、目前单独运行过哪些实验？

> 表中的“单独”仅指**不叠加最终 DFAwareNet/HFMNet 概率融合**；Anchor/LPSM 本身仍依赖其 Teacher 的预测缓存。

| 数据集 | Anchor 主网络 | LPSM 主网络 | 如何判断 |
|---|---:|---:|---|
| **IRSTD-1K** | **72.8351%**（s81；未追加最终外部融合） | 早期另一条 LPSM/SCTransNet 变体约 **68.25%**，训练约 1 epoch 后停止 | **没有最终版缓存式 LPSM 的充分公平对照** |
| **NUAA-SIRST** | **79.1429%**（s83） | **82.3084%**（s1303） / **82.3303%**（s1313） | 都训练过，但 Teacher、输入与训练配置不一致 |

补充：

- IRSTD Anchor s81 后来仅调整推理阈值，mIoU 达约 **72.86%**；再加入面积过滤达到 **73.0367%**。
- NUAA 两个 LPSM 权重（s1303、s1313）作概率融合并附加面积过滤，达到 **82.3730%**。
- 对于 **“Anchor + LPSM 两个完整纠错网络直接联合预测”**，目前**未找到可核实的正式实验记录**。
- 早期 IRSTD 的 LPSM 尝试属于 `sct_lpsm_refiner` 分支，不能直接当成 NUAA 最终 `LPSMAnchorResidualUNet` 配置在 IRSTD 上的公平测试。

**因此，不能直接把 82.33% - 79.14% ≈ 3.19 个百分点解释为 LPSM 新模块的贡献。**

### 指标通俗解释

| 指标 | 含义 |
|---|---|
| **mIoU** | 本项目使用前景目标的全测试集累计交并比，衡量预测目标区域与真值区域的总体重合情况 |
| **nIoU** | 每张图先计算 IoU，再对所有图片求平均；用于观察逐图效果 |
| **F1** | 综合像素级 Precision 与 Recall 的指标 |
| **Pd** | 目标级检测概率：真实目标有多少被检测到 |
| **Fa** | 按项目 SCTransNet 风格计算的虚警量；越小越好，**不等于**简单的 FP 像素数/总像素数 |

项目最终 JSON 还包含 **Precision、Recall 和 `pixAcc`**。但历史计算中的 `pixAcc` 口径与常规全类别像素准确率不同，正式写论文前应复核计算代码与名称。

**必须如实报告的指标取舍：**

- IRSTD-1K 的 **mIoU 提高约 5.18 点，但 nIoU 下降约 0.61 点**。
- NUAA-SIRST 的 **Pd 与基线基本持平**，不能写成检测率显著提高。
- 历史中不同脚本存在 Pd/Fa 计算口径差异，论文应统一为同一套正式评估函数。

### 当前最终推理配方

```text
IRSTD-1K:
P = clip(0.876 × Anchor_noTTA + 0.062 × DFAware + 0.062 × HFMNet, 0, 1)^0.994
threshold = 0.400
8 邻域连通域过滤：min_area = 3

NUAA-SIRST:
Pair = clip(0.45 × LPSM_s1303 + 0.55 × LPSM_s1313, 0, 1)^0.998
P = clip(0.876 × Pair + 0.062 × DFAware + 0.062 × HFMNet, 0, 1)^0.994
threshold = 0.4995
8 邻域连通域过滤：min_area = 3
```

**注意：**两者共享“融合策略”，**并不代表共享同一个完整网络**。

## 六、现有结果距离 SCI 论文还差什么？

### 1. 缺少真正一致的方法

两个数据集当前分别使用 23 通道 Anchor 和 28 通道 LPSM 双分支，教师来源与训练配置也不同。需要固定统一的网络结构、教师输入规则和后处理规则；各数据集**可以分别训练不同权重**，但不能为提高单个数据集成绩随意切换整套算法。

### 2. 历史测试集参与了选参

部分训练脚本会在 `test_cache_spec` 上根据 mIoU 选择最佳 Epoch 和阈值，后续模型融合参数也参考了测试结果。这会造成选择偏差。**在同一测试集上再次运行，不能使它恢复为“从未见过的测试集”。**

后续必须将模型训练、参数选择和最终测试明确分离。必要时使用新的独立数据、可信的留出数据，或明确说明探索性结果的限制；还应审查教师预训练数据是否覆盖目标测试集。

### 3. 缺少公平的消融与统计

需要在**固定教师、输入特征、训练划分、训练预算及阈值选择原则**的条件下比较 Anchor、局部模块、方向模块和完整 LPSM，并至少做少量不同随机种子的复现实验。当前不足 0.1 个百分点的小幅提升，不能在没有稳定性证据时写成显著有效。

### 4. 缺少完整推理效率

已有指标主要集中于检测精度；最终完整方案仍需统计：**参数量（Params）、FLOPs、单图推理时间、FPS、峰值显存**。如果需要多个教师模型提供实时预测，成本必须包含这些上游模型，而不能只统计纠错网络。

### 5. 需要明确原创贡献

大量提升来自强教师预测、多模型互补、阈值调整和后处理。它们可以作为完整系统的一部分，但**不能把相对于 SCTransNet 的全部 +5 点直接归因于自研 LPSM**。此外，后续要检索近期相似论文，确认拟采用的局部—方向融合结构是否具有足够新颖性。

## 七、推荐的技术方案：先验证，再决定如何融合

### 方案 A：两模型输出融合（最快验证互补性）

先分别训练 Anchor 与修复后的 LPSM，使它们对同一图像得到概率图 `A` 和 `B`，再在**独立验证集**选取权重：

```text
P = λ × A + (1 - λ) × B
```

优点是代码改动少，可以快速判断两者是否互补。缺点是需要运行两个网络，效率可能更差，**单纯加权平均通常不足以构成强创新**。尤其当两者错误高度一致时，融合可能无收益。

### 方案 B：单网络结构融合（更适合形成论文方法）

**建议优先考虑**：以 Anchor 的教师锚定残差 UNet 为基础，增加可学习的局部特征分支和修复后的方向上下文分支，在网络内部融合后统一输出修正量。

```text
统一红外图像特征 + 统一 Teacher 概率
                │
                ▼
        共享 Anchor 编码器
                │
          ┌─────┴─────┐
          ▼           ▼
       局部增强     方向上下文
          └─────┬─────┘
                ▼
          自适应门控融合
                ▼
         共享解码器 → 残差修正
                ▼
            最终概率图
```

这是一项**拟议结构，并非仓库已证明成功的结果**。优势是结构统一、便于做消融，也有机会避免两完整网络集成的额外计算成本。是否真的更好，仍须训练验证。

### 建议的最小公平对照实验

| 实验编号 | 设置 | 要回答的问题 |
|---|---|---|
| E1 | 固定 Teacher + Anchor | 基础纠错结构效果如何？ |
| E2 | E1 + 局部保真模块 | 局部特征是否有独立增益？ |
| E3 | E1 + 修复后的方向模块 | 方向上下文是否有独立增益？ |
| E4 | E1 + 两个模块及可学习融合 | 组合后是否进一步提高？ |
| E5（可选） | E4 + DFAwareNet/HFMNet 与后处理 | 额外集成到底贡献多少？ |

**执行原则：**先跑 E1/E4 做可行性筛选；若有可靠增益，再补 E2/E3 消融与多随机种子。两个数据集使用**同一算法定义**独立训练，不用测试集挑选网络与阈值。

## 八、单张 NVIDIA RTX A6000 的计算资源与时间评估

**结论：一张 RTX A6000 48GB 足够开展以上短期验证；不必使用四张卡并行。**

### 仓库中可核实的历史耗时（RTX 2080 Ti）

| 训练记录 | 每个 Epoch 耗时 | 训练轮数 | 备注 |
|---|---:|---:|---|
| Anchor · IRSTD-1K（s81） | 约 316 秒 / 5.3 分钟 | 4 | 512 patch、batch 5、训练缓存较多 |
| Anchor · NUAA-SIRST（s83） | 约 394 秒 / 6.6 分钟 | 4 | 相似结构，但数据处理不同 |
| LPSM · NUAA-SIRST（s1303） | 约 55 秒 | 3 | 每缓存最多 128 条、batch 3、AMP |
| LPSM · NUAA-SIRST（s1313） | 约 58 秒 | 4 | 每缓存最多 128 条、batch 3、AMP |

历史 Anchor 训练显存约 **10.6–10.8GB**；成功 LPSM 训练约 **9–9.6GB**，均有 RTX 2080 Ti 的实验日志作为依据。**LPSM 每轮较快主要与使用训练记录更少有关，不能据此判定它本身计算复杂度更低。**

### A6000 时间预算（计划估计，不是实测）

| 环节 | 预留时间 |
|---|---:|
| 检查环境、已保留模型与门控 | 5–15 分钟 |
| 两个数据集 × 两个主网络的 3–4 Epoch 短训练 | 约 40–90 分钟 |
| 验证评估、指标对比、实验记录 | 约 20–60 分钟 |
| **预留总时间** | **约 1–3 小时** |

**前提条件：**上游 Teacher 预测缓存已准备完毕，脚本可直接运行，初期只需短训练，没有重新生成多个大模型的预测；统一特征、修复代码及分割验证集产生的工程准备不计入上述短训练预算。若要重新计算教师缓存、完整消融、多随机种子或重新建立独立测试，实际耗时可能显著增加。

建议**不要为了用满 A6000 的显存而盲目增大 batch size**，否则实验条件改变，难以公平比较。先做一组小规模测速，再更新估计。

## 九、推荐的下一步执行顺序

1. **冻结历史结果**：保留目前所有旧权重、报告、概率图和对比表，不覆盖已有探索证据。
2. **核查数据与教师来源**：明确 train/val/test，各来源数据是否与 SIRST3 重复、上游教师是否见过测试图像。
3. **统一两组网络的输入条件**：让 Anchor 与 LPSM 在相同 Teacher、同样输入通道、相同训练预算上公平比较。
4. **修复 LPSM 方向门控并做活性测试**：验证方向分支梯度不为零、输出确实受方向特征影响。
5. **使用一张 A6000 跑短训练**：先评估 E1/E4，在 IRSTD-1K、NUAA-SIRST 都使用统一定义的结构。
6. **再决定是否融合两套网络**：若修复后的 LPSM 自身显著更好，优先考虑单模型；如果预测互补明显，再做外部概率融合实验。
7. **完成论文级证据**：控制变量消融、多随机种子、独立测试、可视化和完整效率指标。

**最终建议：先证明“同一条件下 LPSM 相对 Anchor 是否有真实贡献”，再决定要不要将两个完整模型拼接。** 当前研究更应追求可解释、可复现、能归因于自己的创新，而不是继续在已参与调参的测试集上追逐最高分。
