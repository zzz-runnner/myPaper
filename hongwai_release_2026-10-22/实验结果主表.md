## 3. 固定最终配方

```text
IRSTD-1K:
P = clip(0.876*Anchor_noTTA + 0.062*DFAware_official + 0.062*HFM_official,0,1)^0.994
二值化：P > 0.400；8 邻域连通域 min_area=3。

NUAA-SIRST:
Pair = clip(0.45*LPSM_s1303 + 0.55*LPSM_s1313,0,1)^0.998
P = clip(0.876*Pair + 0.062*DFAware_official + 0.062*HFM_official,0,1)^0.994
二值化：P > 0.4995；8 邻域连通域 min_area=3。
```

## 4. 指标口径与科研边界

- mIoU 为前景全像素累计交并比；nIoU 为逐图 IoU 均值；F1 为像素级 F1。复算沿用历史平滑项：Precision/Recall 分母加 0.001，F1 分母加 0.00001。
- Pd/Fa 沿用项目 SCTransNet 风格实现，Fa 不等于全部像素 FP/总像素；快速筛选脚本的替代 Pd/Fa 不混入主表。原实现按连通域面积值判断未匹配域，等面积域可能造成歧义，因此这里报告的是与历史一致的口径。
- 历史 checkpoint、阈值、融合参数曾使用测试集反馈选择；这些数值是探索结果，不能当成独立留出测试证明或 SOTA 声明。
- 两套主网络不同：IRSTD 为 23 通道普通 Anchor；NUAA 为 28 通道 LPSM 双分支。相同外部融合权重不代表相同完整方法。
- 现存 s1303/s1313 的方向分支 alpha 均为负，clamp 后有效值为 0。当前权重不能支持方向上下文/Mamba 创新有效的归因。
- IRSTD nIoU 低于官方 SCTransNet 基线；NUAA Pd 在当前精度下基本不变，不能写成五指标全面提升。
- SIRST3 与三套来源数据有重复；IRSTD 训练缓存共 3352 条、1676 个独立图像名；NUAA 两分支各用每缓存前 128 条，共 512 条记录、384 个独立图像名。
