# 实验协议和限制

主表记录的是历史探索结果：训练/阈值/融合参数曾多次参考测试集，不能重新命名为严格留出泛化结果。这里保留原程序，以免改变历史数值；未来实验需固定独立验证协议。

IRSTD 主网络为普通 Anchor、23 输入通道，NUAA 为 LPSM 双分支、28 输入通道。共享外部融合系数不等于同一完整模型。两份 NUAA 权重的方向门控 alpha 均为负，经 clamp 后为 0；不支持方向分支/Mamba 创新有效的归因。

mIoU 为前景累计交并比，nIoU 为逐图均值；F1 使用历史平滑项。Pd/Fa 使用 `external/SCTransNet/metrics.py` 原实现；其未匹配连通域按面积值判断，等面积域可能产生歧义，为对齐历史未改写。不要混用快速筛选脚本的替代 Pd/Fa。

SIRST3 是合并集，不能视为独立来源。IRSTD s81 使用 3352 条缓存记录、1676 个不同图像名；NUAA 各分支每缓存前 128 条，512 条记录、384 个不同图像名。2026-09-17 审计未发现训练与两目标测试集像素精确重复，但没有完成近重复/所有第三方训练来源审计。

当前未提供统一网络的双数据集控制变量消融、多随机种子置信区间或完整上游推理成本。缓存复算与现存权重检查不等同于从原图重建全部上游的复现。
