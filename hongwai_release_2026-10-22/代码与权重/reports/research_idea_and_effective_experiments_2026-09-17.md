# 红外小目标项目：科研思路与有效实验审计

审计日期：2026-09-17。项目：`/home/cx/hongwai/irstd-lab`。

本报告核对现有代码、训练日志、summary、评估 JSON 和缓存。本轮没有重新训练、没有搜索新阈值、没有删除旧实验；对两个已保留最终配方重新计算了指标，并检查了数据重复。历史实验主要记录于 2026-06-09 至 2026-06-16。

## 1. 核心结论

- 已保留主线最终结果可以复算：IRSTD-1K mIoU **73.2142%**，NUAA-SIRST **82.7020%**。
- 相对本地官方 SCTransNet 权重评估的 68.03% / 77.64%，数值上分别提高约 **5.1842 / 5.0620 个百分点**。但这是经过大量测试集反馈筛选的探索结果，不是独立留出测试的泛化增益证明。
- 两套最终配方的主网络、教师来源、输入通道和训练规模不同。目前只能说共享“教师锚定残差修正和外部概率融合”的研究方向，不能直接声称同一个完整网络在两套数据上获得上述结果。
- **新发现：两个保留 LPSM 权重的方向上下文门控均被截为 0，方向模块实际退化为恒等映射。** 当前结果不能证明长程方向上下文有效，更不能作为 Mamba/状态空间机制有效的证据。
- 当前最值得继续验证的创新候选是“教师锚定的有界残差修正 + 局部保真/方向上下文融合”，但方向分支必须先恢复可学习性并重新验证。较大的已有收益来自强教师与多模型互补，LPSM 命名网络的增量收益较小，尚缺严格消融和重复实验。
- 没有五项指标全面提高：IRSTD 最终 nIoU 低于官方 SCTransNet 本地基线；NUAA 最终 Pd 基本未变。

## 2. 科研问题、假设和实现

### 2.1 真正要解决的问题

红外小目标往往只有少量像素、对比度低。局部亮点和高频响应既可能来自目标，也可能来自云边、地物边缘等杂波。只增强局部响应会引入虚警，只扩大上下文又可能抹去小目标。

因此主假设是：保留已有检测器提供的目标证据，结合局部对比度、背景结构和跨方向上下文，只对不可靠区域做受限修正，同时关注虚警抑制与漏检恢复。

三份用户材料分别提供同领域 IRSTD 方法、目标/杂波高频区分思路，以及 FeatUp、UniVAD、SAMRefiner、MambaIR/MSVMamba 等跨领域迁移方向。这些是启发来源，不代表已经完整复现其中所有论文。

### 2.2 代码中实际存在的流水线

```text
红外图像 + 多个已有检测器的预测缓存
  -> 图像特征 / 教师统计 / 教师概率
  -> Anchor 或 LPSM 残差网络
  -> 在教师 logit 上叠加有界修正
  -> 与 DFAwareNet、HFMNet 概率图融合
  -> 阈值二值化 + 8 邻域连通域面积过滤
```

核心公式：

```text
Delta = s * tanh(R_theta(F))
P_refined = sigmoid(logit(P_teacher) + Delta)
Loss = weighted_BCE + Dice_or_weighted_Dice + lambda * mean(Delta^2)
```

`s` 限制每个像素的 logit 修正幅度，残差平方惩罚限制偏离教师的程度，但两者都不能数学保证保留所有真目标或提高指标。

图像特征包含：归一化图像；7/15/31 窗口局部对比度和局部 z-score；9/17 top-hat；DoG/Laplacian；降采样再重建的背景及残差。后者是背景近似，**不是实际低秩分解算法**。另有教师概率、各专家预测及 max/min/std 等统计。

LPSM 的具体实现：深度卷积局部分支 + 上下左右四方向累计均值 + 卷积混合 + 门控残差，在成功配置的 `e2,mid` 层启用方向模块。代码使用 `torch.cumsum`，**不是 MambaIR 原模型，也不是 selective state-space scan**。官方 Mamba 算子用于外部 DFAwareNet/HFMNet，二者必须明确区分。

NUAA LPSM 训练还对教师误报的背景、教师漏掉的目标、不确定像素增加损失权重。IRSTD 保留 Anchor 分支没有采用同一套 LPSM 结构与完整加权设置。

代码依据：[特征与教师构造](../scripts/train_teacher_anchor_refiner_from_cache.py)、[LPSM 与训练损失](../scripts/train_lpsm_anchor_refiner_from_cache.py)。

### 2.3 保留权重的关键发现：方向分支没有参与输出

`DirectionalIntegralStateBlock` 实际返回：

```text
x + clamp(alpha, 0, 1) * gate * state
```

`alpha` 从 0 初始化，但保留的成功权重中四个 alpha 都已变成负数。本轮直接读取权重，不是从日志推测：

| 权重 | 方向模块 | 保存的 alpha | 前向有效 alpha |
|---|---|---:|---:|
| s1303，最佳 epoch=3 | e2 | -0.0001357362 | 0 |
| s1303，最佳 epoch=3 | mid | -0.0001921713 | 0 |
| s1313，最佳 epoch=1 | e2 | -0.0002041643 | 0 |
| s1313，最佳 epoch=1 | mid | -0.0002041781 | 0 |

本轮将四个模块各自恢复到 CPU，以随机张量检查，`max(abs(block(x)-x))` 均为 **0.0**，与公式判断一致。

这意味着局部卷积和外层 `0.15 * local_preserve` 路径仍在，但方向上下文及其门控混合对这两个最终模型的输出没有贡献。负值区间的 clamp 导数为 0，也会阻断这一路正常学习。既有数值仍然真实可复算，只是不能把收益归因于当前关闭的方向模块。

**本轮没有修改网络或训练任何新权重。** 该发现改变对创新的解释，不改变历史分数。下一步应先修复门控参数化并加入分支活性检查，再做同预算对照，而不是直接把它写成有效长程建模模块。

### 2.4 创新候选与证据边界

| 内容 | 当前实际工作 | 证据与判断 |
|---|---|---|
| 教师锚定的有界残差修正 | 已实现、已训练，两套数据均尝试过 | IRSTD 取得正向探索结果；尚未通过同教师、同训练预算的完整消融证明贡献 |
| 局部保真与方向上下文协同 LPSM | 已实现；NUAA 保留两个分支，但方向门控均为 0 | 只有 LPSM 命名网络的数值提升；不能证明方向分支有效，须先修复再消融 |
| 杂波抑制、漏检恢复加权 | 已实现于训练损失，另有局部规则 | 符合任务动机；不能把整条融合流水线的全部收益归给该损失 |
| 多专家互补 | PConv、BGM、RPCANet、DFAwareNet、HFMNet 等预测被使用 | 是目前重要效果来源，但概率加权本身不是充分的新颖性论证 |
| 连通域面积过滤 | 已评估且可带来小幅提升 | 标准后处理，应单独报告；可能删除真实极小目标 |
| 正确启用官方 Mamba 后端 | 编译和推理适配完成 | 属于复现工程修正，不是新算法贡献 |

现阶段可以称为“创新候选”，不能仅凭模块命名和最高分认定已形成被实验充分支撑的新方法。

SIRST3 由前三套数据合并，不是第四个独立来源。本轮实际读取缓存元数据确认：

- IRSTD s81：`max_train_samples_per_cache=0`，使用 800+213+663+1676=3352 条缓存记录，只有 **1676 个不同图像名**。不能宣传为 3352 张独立训练图像。

- 上述检查不等价于近重复/同场景审计，也不证明所有外部预训练权重的训练数据都无污染，后者仍需核对原论文、发布说明及划分。

## 6. 两套最终方法是否相同

确切配方：

```text
IRSTD:
P = (0.876 * Anchor_noTTA + 0.062 * DFAware_official
     + 0.062 * HFM_official)^0.994
threshold=0.400, min_area=3

NUAA:
Pair = (0.45 * LPSM_s1303 + 0.55 * LPSM_s1313)^0.998
P = (0.876 * Pair + 0.062 * DFAware_official
     + 0.062 * HFM_official)^0.994
threshold=0.4995, min_area=3
```

| 项目 | IRSTD-1K | NUAA-SIRST |
|---|---|---|
| 主修正网络 | 普通 Anchor Residual UNet，单分支 | LPSM Anchor UNet，双分支，宽度 56/64 |
| 教师模式 | avg | local_rule |
| 输入通道 | 23 | 28 |
| 教师来源 | baseq/refiner/PConv-D05/PConv-P43 | 多源 strong_fusion/BGM/RPCANet 等，NUAA 缓存再含官方 Mamba 融合 |
| 训练缓存使用 | 全量，但含合并集重复 | 每缓存前 128 条 |
| 最终外部融合权重 | 0.876/0.062/0.062 | 0.876/0.062/0.062 |
| 最终面积下限 | 3 | 3 |

**相同融合权重不等于相同完整方法。** 同一种方法可以在不同数据集分别训练，产生不同权重文件；当前关键差异不是 checkpoint 文件不同，而是架构、教师输入和执行流程不同。

历史交叉检查并没有完成“NUAA 的 LPSM pair 原方法训练并评估到 IRSTD”。当时用 IRSTD Anchor 代替了主源，所以 73.2142 是融合策略迁移结果，不是 LPSM 在 IRSTD 的结果。同样，NUAA Anchor 权重已删除，79.1429 也不是精确 `no-TTA + min_area=6` 重评结果。

缓存教师在推理时仍然需要。不能把本方法写成只依赖单个轻量学生网络，更不能只按最终三项加权就声称总共只有三个模型。端到端速度、显存、参数量必须包含上游教师生成和双分支推理。

## 8. 论文证据的主要缺口

1. **创新分支未生效。** 保留 LPSM 的方向分支因负 alpha 被 clamp 为 0，不能以目前结果支持长程上下文机制有效。
2. **测试集参与选择。** Anchor/LPSM 脚本按 `test_cache_spec` 上不同阈值的 mIoU 选择 best checkpoint。LPSM pair 和外部融合脚本又在 test maps 上排序选权重、阈值、面积。部分名为 train-selected 的搜索还会评估多个验证候选并按测试结果重新挑选。因此历史报告中的 strict、reliable、合法提升等措辞不能直接沿用为科研保证。
3. **内部验证不一定是模型未见的数据。** 在已有训练缓存里再划验证集，只能说明融合参数的选择来源；上游专家是否训练过这些图像还要核对。更可靠的融合训练应采用真实留出或 out-of-fold 预测。
4. **没有统一完整方法的双数据集结果。** 需固定网络、教师输入定义、训练和推理规则；各数据集可以独立训练，但不要逐数据集换成功架构。
5. **缺少控制变量消融。** 同一教师和预算下比较：教师本身、普通 Anchor、仅局部分支、仅方向上下文、完整 LPSM；再分别加入外部集成和后处理。不要把不同教师、多模型数量和测试阈值变化混入模块贡献。
6. **缺少统计和成本证据。** 当前小于 0.1 个百分点的增益需多种子及区间估计；效率报告需包含整个上游流水线。成功配置可以在 2080 Ti 上分卡运行，但没有证明全流水线轻量或实时。
